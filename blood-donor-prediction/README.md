# Blood Donor Prediction

A simple Flask + Machine Learning project that predicts whether a person is likely to donate blood.

## Project Structure

```text
blood-donor-prediction/
├── templates/
│   └── index.html
├── blood_donor_analysis.py
├── app.py
├── requirements.txt
├── transfusion.csv
├── .gitignore
└── README.md
```

## Setup

1. Create a virtual environment.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Train the model:

```bash
python blood_donor_analysis.py
```

4. Start the Flask application:

```bash
python app.py
```

5. Open the local Flask URL shown in the terminal.
